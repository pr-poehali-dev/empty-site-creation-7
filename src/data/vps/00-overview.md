# Сервер VPS и парсинг — общее

**Статус:** этап 1 сделан (VPS FirstVDS арендован), этап 2 и основа этапа 3 готовы, ждём установки на сервер.

## Зачем
Цены маркетплейсов в каталоге приёмки (режим «Технические») ищутся функцией `market-prices`. Wildberries и Ozon пускают только **настоящий браузер**: сначала их защита заставляет браузер выполнить свою проверку, и только потом отдаёт данные. Простой запрос эту проверку не проходит — даже через домашние прокси.

## Итоги проверки (тестовая модель Blackton TP536)
| Сайт | Способ | Результат |
|---|---|---|
| М.Видео | напрямую | ✅ 2 854 ₽ |
| Яндекс Маркет | прокси Россия | ✅ 3 661 ₽ |
| WB РФ / WB РБ | прокси Россия / Беларусь | ❌ код 403 (сервер `wbaas`, пустой ответ) |
| Ozon РФ / Ozon РБ | прокси Россия / Беларусь | ❌ проверка «я не робот» (challenge) |

Мобильные входы WB (`appType=32`) и Ozon (`api.ozon.ru`, заголовки приложения) тоже закрыты.

## Как будет работать
Кнопка «Получить цену» по WB/Ozon → функция цен отправляет задание на VPS → там Chromium открывает поиск через прокси Proxy.Market (Россия для РФ, Беларусь для РБ) → возвращает карточки с ценами → сверка модели и средняя цена — как сейчас. Яндекс Маркет и М.Видео браузер не используют (быстрее).

## Какие варианты рассматривали
- **Иностранные сервисы-парсеры** (Scrapfly, ZenRows, ScraperAPI) — отказались: зарубежная оплата, нет гарантии.
- **Сервисы аналитики WB/Ozon** — смотрели, не подходят (таблица ниже).
- **Выбрано: свой VPS с браузером** — примерно 500–900 ₽ в месяц, работает и для РФ, и для РБ, трафик Proxy.Market уже оплачен.

### Сервисы аналитики
| Сервис | Цена в месяц | API для цен |
|---|---|---|
| MPStats | 12 990 ₽ (акция −50%) | есть на всех тарифах, пробный доступ 24 часа |
| SalesFinder | 3 500–9 000 ₽ | не подтверждён |
| Маяк (только Ozon) | от 5 917 ₽ | не подтверждён |
| MarketGuru | 4 990–29 990 ₽ | не подтверждён |
| SellerStats | 2 490–15 990 ₽ | не подтверждён |
| Stat4Market | 3 900 ₽ | не подтверждён |
| Shopstat, SellerFox | бесплатно | вряд ли |

Общие минусы: нет Беларуси (BYN), данные за вчера, это аналитика ниш, а не поиск цены по модели, и дорого.
