# Важно учесть

- **Скорость:** через браузер одна цена ищется около **5–15 секунд**, при повторных запросах (куки уже есть) быстрее.
- **Трафик Proxy.Market:** примерно **0,5–1 МБ на поиск**. Тестовых 100 МБ хватит примерно на 100–200 проверок. Полный проход 2 217 моделей по 4 сайтам WB и Ozon — примерно 5–9 ГБ, около 1–2 тыс. ₽ трафика. Для массового парсинга трафик нужно докупить.
- **Гарантия:** настоящий браузер с домашним адресом обычно проходит защиту WB и Ozon, но точно покажет только проверка. Если какой-то сайт не пустит — сказать прямо и искать вариант (например, MPStats только для РФ).
- **Если WB или Ozon поменяют защиту:** может понадобиться обновить программу сервера (кнопка «Обновить программу»).

- WB пустил после того, как браузер перестал называть себя «HeadlessChrome».
- Ozon, судя по всему, отсекает по признакам сервера: видеокарта программная (SwiftShader), сервер в дата-центре. Следующие варианты: Chrome вместо Chromium, другой браузер (Firefox), или мобильные прокси.
- **Проба Chrome (27.10.2026):** Google Chrome 156 поставлен на сервер в `/opt/pricebot/extra/chrome` — Ozon тоже не пускает (и без окна, и с окном). Ozon проводит проверку браузера (запрос `abt/result`) и отклоняет её.
- **Firefox (27.10.2026):** библиотеки поставлены владельцем. Ozon в Firefox показывает капчу-пазл «Сопоставьте пазл, двигая ползунок» — это дальше, чем у Chrome (там сразу отказ). Если Firefox притворяется Windows — снова отказ «нет соединения». WB после всех проб работает.

## Проверка Ozon с телефона (сделано, версия 1.1.2)
- Для Ozon на сервере отдельный постоянный Firefox (виртуальный экран), пропуска хранятся отдельно от WB: `oz_cookies_ru.json`, `oz_cookies_by.json`.
- Окно «Проверка Ozon РФ / РБ»: живая картинка с сервера, автоматически увеличенный пазл (кнопка «Весь экран / Пазл»), палец тянет ползунок — движение передаётся на сервер частями каждые 0,6 с, после отпускания — новый снимок.
- Если Ozon снова попросит пазл, в таблице цен статус «нужна проверка Ozon».
- Ozon иногда с первого раза отвечает «нет соединения» — окно открытия делает до 2 попыток, иначе кнопка «Обновить».

## Решение для Ozon (27.10.2026) — мобильные прокси
- Пазл с телефона не помог: после пазла Ozon всё равно отказывал. Окно пазла убрано.
- Владелец купил тестовый мобильный пакет Proxy.Market (100 МБ). Мобильные прокси есть и для России (МТС), и для Беларуси (A1, Минск).
- Ozon пускает браузер, который выглядит как телефон Android, с мобильного адреса — без пазла. Карточки берутся прямо со страницы поиска (внутренний запрос Ozon РФ закрыт).
- Цены рассрочки «× 12 мес» отбрасываются.
- WB через мобильные прокси работает хуже — WB оставлен на домашних прокси (пакет 1 ГБ).
- Итог проверки (Blackton TP536): WB РФ 4 037 ₽, WB РБ 151,10 BYN, Ozon РФ 2 534 ₽, Ozon РБ 113,58 BYN.
- Расход мобильного трафика: около 40 МБ за ~25 поисков вместе с пробами. Для постоянной работы понадобится пакет больше.
