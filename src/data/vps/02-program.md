# 2. Программа для сервера

**Статус:** не начато. **Делает:** Юра.

## Браузер-сервер
- Держит открытым **Chromium** (Playwright) и **запоминает куки** WB и Ozon. Проверку «я не робот» обычно нужно пройти один раз, а не на каждом запросе.
- **WB** — перехватывает ответ поиска со списком товаров.
- **Ozon** — берёт карточки со страницы поиска.
- **Не грузит** картинки, видео и шрифты, чтобы экономить трафик прокси.
- Выполняет **2–3 задачи одновременно**, остальные ставит в очередь.

## Защита
- Принимает команды только с **секретным ключом**.
- Соединение **шифрованное**. Сертификат сервер делает сам, сайт запоминает его отпечаток — подставить чужой сервер нельзя.
- Данные прокси **не хранятся** на VPS: они приходят вместе с каждым заданием.

## Установка и обновление
- **Скрипт установки:** ставит Chromium и программу, включает автозапуск после перезагрузки, закрывает лишние порты.
- **Самообновление:** по кнопке с сайта сервер сам скачивает новую версию.
- Файлы программы лежат на сайте. После изменений сайт нужно **опубликовать**, чтобы сервер смог их скачать.
