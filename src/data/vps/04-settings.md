# 4. Настройки в каталоге

**Статус:** не начато. **Делает:** Юра.

## Новая вкладка «Браузерный сервер»
(в окне «Настройки» каталога, рядом с «Настройка прокси» и «Маркетплейсы»)
- **Команда установки** с кнопкой «Скопировать», ключ уже вшит внутрь.
- **Статус:** на связи или нет, версия, сколько задач выполнено, сколько работает без перезапуска.
- **Кнопки:** «Проверить связь», «Перезапустить браузер», «Очистить куки», «Обновить программу».

## Вкладка «Маркетплейсы»
- Вместо переключателя «через прокси» — **выбор из трёх способов**: напрямую / через прокси / через браузер.
- **WB РФ, WB РБ, Ozon РФ, Ozon РБ** сразу ставятся «через браузер».
- Яндекс Маркет — через прокси, М.Видео — напрямую (как сейчас).
