# 3. Функция цен

**Статус:** готово — способ поиска у каждого сайта, поиск WB/Ozon через браузер на сервере, понятные ошибки. **Делает:** Юра. **Новую функцию не создаём** — всё в `market-prices`.

## Что добавить
- **В базе:** данные сервера — адрес, ключ, отпечаток сертификата, статус.
- **Саморегистрация:** команда установки содержит одноразовый код. Сервер сам сообщает сайту свой адрес и ключ, вручную вводить ничего не нужно.
- **Способ поиска у каждого сайта:** «напрямую / через прокси / через браузер» (сейчас только «через прокси» да/нет).
- **Прокси для задания:** берутся из настроек Proxy.Market и передаются серверу вместе с заданием.
