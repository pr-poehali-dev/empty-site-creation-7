# 5. Запуск

**Статус:** не начато. **Делаем вместе.**

1. Владелец открывает «Каталог приёмки» → «Настройки» → «Браузерный сервер» → **«Скопировать команду»**.
2. В панели хостинга открывает **«Консоль»** VPS, вставляет команду и ждёт **3–5 минут**.
3. Карточка в настройках сама становится **«на связи»**.
4. Юра жмёт **«Проверить»** по всем 6 сайтам и показывает результат.
5. Владелец поднимает **таймаут функции цен до 30 секунд**: Ядро → Функции → `market-prices` → Настройки. Без этого поиск через браузер будет обрываться.
