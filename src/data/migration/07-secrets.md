# Этап 7. Секреты

## Задача

На странице восстановления у каждого поля: пометка **обязательно/необязательно**, короткая подсказка и раскрывающаяся пошаговая инструкция «где взять».

| Поле | Где взять |
|---|---|
| Токен бота Телеграма | @BotFather → /mybots → бот → API Token. Если мог утечь — там же Revoke |
| Имя бота | Там же, без @ |
| Секрет защиты бота | Кнопка «Сгенерировать» |
| Ключ обмена с 1С | Из обработки обмена в 1С, или сгенерировать новый и вписать в обработку |
| 1С OData (Трейд-Ресурс): адрес, логин, пароль | 1С: «Настройка автоматического REST-сервиса» → «Авторизация». Адрес — от 1С-провайдера |
| 1С OData (Фомкин, Мир техники) | Там же. Необязательные — сейчас не заполнены |
| Ключ планировщика | Кнопка «Сгенерировать» |
| Ключ Яндекс Диска | oauth.yandex.ru, инструкция внутри |
| Адрес сайта для бота | Подставляется сам из домена |
| База, хранилище | Создаются сами |

### Ручные шаги после переноса

Страница показывает их списком с инструкциями:

- @BotFather → /setdomain → новый домен (вход через Телеграм);
- адрес мини-приложения аукциона в @BotFather;
- новый адрес обмена в обработке 1С — страница показывает готовую ссылку;
- новый домен в Яндекс Метрике.
