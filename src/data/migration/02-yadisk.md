# Этап 2. Яндекс Диск

## Задача

Каждая копия — ручная и автоматическая — **сама уходит на Яндекс Диск**. Копия живёт в двух местах: пропадёт хранилище сайта — останется на Диске.

- **Подключение:** поле для ключа доступа к Диску в настройках архивации + пошаговая инструкция, как его получить (oauth.yandex.ru → создать приложение → доступ к Диску → токен). Кнопка «Проверить подключение» показывает свободное место.
- **Папки:** `Резервные копии/ГГГГ-ММ-ДД_ЧЧ-ММ/` — база, файлы, паспорт, установщик, инструкция.
- **Статус у каждой копии:** «на сервере» / «на Диске» / «ошибка отправки». Повтор при ошибке, уведомление в Телеграм.
- **Кнопка «Отправить на Диск»** для ручной отправки.
- **Своё хранение на Диске,** например 30 последних. Старые удаляются сами, защищённые — нет.
- **Код** на Диск кладётся вручную. Сайт видит дату файла кода в папке и напоминает: «Код на Диске от 12.09 — положите свежий».
