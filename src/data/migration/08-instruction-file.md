# Этап 8. Инструкция-файл

## Задача

`ИНСТРУКЦИЯ ПО ВОССТАНОВЛЕНИЮ.txt` — в каждой папке копии на Диске и в каждом скачанном комплекте. Обычный текст, открывается где угодно.

Содержание:

- **Что в папке:** какой архив за что отвечает, дата копии.
- **Что подготовить:** VPS (какой, параметры), домен, значения секретов, свежий код из «Скачать → Скачать код».
- **Шаги с нуля:** аренда сервера → направить домен → найти консоль → вставить готовую строку → открыть `/restore` → что вводить.
- **Обновление рабочего сайта** через `/update`.
- **Справочник секретов** — где взять каждый.
- **Ручные шаги после переноса:** Телеграм, 1С, Метрика.
- **Если что-то пошло не так:** частые ошибки и что делать.

Эта же инструкция — на сайте в разделе архивации и внутри установщика.
