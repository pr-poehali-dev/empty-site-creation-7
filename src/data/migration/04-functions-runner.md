# Этап 4. Переходник функций

## Задача

Один сервис на VPS, который запускает **все 45 функций** без переделки их кода по адресам `https://домен/api/имя-функции`.

Повторяет поведение платформы поехали:

- формат запроса и ответа функции (метод, заголовки, параметры, тело);
- заголовки входа: `Authorization` → `X-Authorization`, `Cookie` → `X-Cookie`, `X-Set-Cookie` → `Set-Cookie`;
- ограничение по времени для каждой функции;
- секреты — как переменные окружения;
- **расписание:** планировщик, автокопии, отправка на Диск;
- **хранилище файлов** на самом VPS с тем же поведением, что `bucket.poehali.dev`, и раздача файлов по адресам нового домена.
