# Этап 6. Установщик и обновление

## Задача

### Первая установка — `/restore`

**Одна команда** в консоли VPS (в ЛК хостера кнопка «Консоль», вставить строку, Enter, 5–10 минут). Ставит базу, веб-сервер, сертификат безопасности, хранилище, переходник функций. В конце пишет адрес страницы восстановления и пароль.

Страница `https://домен/restore` по шагам:

1. **Пароль установки.**
2. **Архивы:** с Яндекс Диска (ввести ключ → список копий → выбрать) или с компьютера.
3. **Проверка целостности.**
4. **Новый домен** + проверка, что он смотрит на этот сервер. Кириллица переводится сама.
5. **Секреты** с подсказками (этап 7).
6. **«Восстановить»** с прогрессом по пунктам.
7. **Отчёт** + список ручных шагов.
8. **Страница отключается,** дальше работает `/update`.

### Обновление рабочего сайта — `/update`

VPS — рабочий сайт, поехали — мастерская. Обновление приносит **код и структуру базы**, данные VPS не трогает.

**Режимы:**

1. **Обновление (обычный).** Новый код сайта и функций + новые изменения структуры. Данные, файлы, секреты VPS остаются.
2. **Полная замена с данными.** Только для первого переезда или полного сброса, двойное подтверждение.

**Шаги обновления:**

1. В мастерской сделали доработку, проверили. Скачиваете код: «Скачать → Скачать код».
2. Кладёте на Яндекс Диск или загружаете с компьютера.
3. На VPS: `https://домен/update` → пароль → выбрать архив.
4. **Предпросмотр:** версия «было → станет», какие изменения структуры добавятся («2 таблицы, 5 полей, удалений нет»), какие новые секреты нужны. Изменение, которое **удаляет** таблицу или поле, — пауза и отдельное подтверждение.
5. **Страховочная копия VPS** (код + база + файлы) — автоматически.
6. **Плашка «Идёт обновление»** на 2–3 минуты. Подмена кода, применяются **только новые** изменения базы (VPS помнит применённые), домен прописывается сам.
7. **Самопроверка.** Не прошла — автооткат к страховочной копии.
8. **Отчёт, журнал обновлений,** кнопка «Откатить последнее обновление».

**Защиты:**

- предупреждение, если ставится версия старее текущей;
- страховочная копия обязательна — без неё обновление не стартует.
