# Этап 1. Полная копия

## Задача

На странице «Архивация данных» — кнопка **«Создать полную копию»**, которая собирает:

- **базу** со структурой: таблицы, поля, связи, индексы, счётчики и все данные;
- **файлы** из хранилища: фото каталога и лотов, файлы от Юры, накладные;
- **паспорт**: список секретов без значений, старый домен, что менять при переносе, контрольные суммы, дата.

Кроме того:

- скачивание каждого архива отдельно и кнопка «Скачать установщик»;
- подсказка, что код скачивается через ЛК поехали «Скачать → Скачать код», лучше в тот же день;
- проверка целостности каждой копии;
- автокопирование по расписанию, по умолчанию ежедневно в 03:00;
- файл `ИНСТРУКЦИЯ ПО ВОССТАНОВЛЕНИЮ.txt` в комплекте.
