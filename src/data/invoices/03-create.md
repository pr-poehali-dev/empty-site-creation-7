# Этап 3. Создание карточек на сайте

## Что делаем

Строки счёта, которые не нашлись в каталоге, превращаем в **полноценные товары — только на сайте**.

В 1С на этом этапе не обращаемся вообще.

## Реквизиты — заполняем впрок

Заполняем сразу всё, что понадобится при выгрузке в 1С. Реквизиты просто лежат в карточке и ждут пятого этапа:

| Реквизит | Откуда берём |
|---|---|
| Артикул | Из счёта, **буква в букву** |
| Штрихкод | Из счёта, если есть |
| Наименование | Из счёта |
| Наименование полное (для печати) | Из счёта / формируем |
| Вес брутто | Уточнить: по умолчанию или вручную |
| Способ списания | **Всегда FIFO** |
| Ставка НДС | **Без НДС** |
| Единица измерения | Уточнить значение по умолчанию |
| Вид номенклатуры | Уточнить: по умолчанию или вручную |
| Группа | Выбирается владельцем |

## Пометка «в 1С не выгружен»

Каждая новая карточка помечается как неотправленная. По этой пометке пятый этап поймёт, что именно выгружать.

## Полноценные товары, не временные

Товар создаётся как обычная карточка каталога. Механизм **временных товаров здесь не используется** — он остаётся для заявок.

## Подстраховка перед созданием

Перед тем как заводить, показываем список: «вот эти товары будут созданы заново, проверь». Иначе при ошибке сопоставления получим дубль и на сайте, и потом в 1С.

## Чего на этом этапе не делаем

- Не проставляем цены — это четвёртый этап
- Не обращаемся к 1С — это пятый этап

## Открытые вопросы

**Вес брутто и вид номенклатуры** в счёте обычно не указаны. Откуда брать — ставить значение по умолчанию или вводить руками при создании?

## Решения по этапу

- Способ списания всегда FIFO
- Ставка НДС — без НДС
- Артикул записывается ровно как в счёте
- Создаём полноценные карточки, не временные товары
