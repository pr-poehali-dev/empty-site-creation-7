# Этап 5. Выгрузка в 1С

## Главное правило

**Сайт не отправляет в 1С ничего сам.** Только по команде владельца.

Владелец смотрит на готовый результат — товары созданы, цены проставлены, — всё проверяет и жмёт **«Выгрузить в 1С»**.

## Что уходит по кнопке

**1. Новые товары** — те, что помечены «в 1С не выгружен». Создаются в справочнике номенклатуры со всеми реквизитами из третьего этапа.

**2. Документ установки цен** — один документ на весь счёт, со всеми строками. Не по документу на товар.

Отправка идёт **пачкой**, а не по одному товару — чтобы не дёргать 1С на каждую позицию.

## Как это работает технически

Через OData — стандартный интерфейс платформы 1С. Обработки в 1С писать не нужно, сайт обращается к базе напрямую.

Ключ доступа к 1С хранится в секретах проекта, в коде его нет.

## Журнал отправок

Обязателен. Видно, что ушло, что не прошло и почему. Без журнала при ошибке придётся гадать вслепую.

## Подводные камни

**Типы цен — отдельный справочник в 1С.** Четыре цены сайта (базовая, розничная, оптовая, закупочная) нужно один раз сопоставить с типами цен в УНФ. Разовая настройка.

**Реквизиты по умолчанию.** Единица измерения, ставка НДС, вид номенклатуры, группа — задаются один раз и подставляются автоматически.

**Проведение документа может не пройти**, если в конфигурации на документ навешаны проверки. Тогда документ создастся непроведённым и его придётся провести вручную в 1С. Узнаем только на практике.

## Удобство

Можно разобрать счёт вечером в дороге, а выгрузить утром — когда будешь у компьютера и сможешь проверить, как всё легло в 1С.

## Решения по этапу

- Выгрузка строго по команде владельца, автоматически ничего не уходит
- Один документ установки цен на весь счёт
- Отправка пачкой, не по одному товару
