# Этап 6. Возврат идентификаторов

## Что делаем

1С отвечает идентификаторами созданных товаров. Записываем их в карточки на сайте.

## Зачем

Идентификатор — это связь карточки на сайте с номенклатурой в 1С. Пока его нет, товар для 1С чужой. Как только записан — товар становится обычным: дальше его цены обновляются наравне с остальными, без повторного создания.

## Состояние каталога

Фундамент уже есть: **20 628 товаров из 20 632 связаны с 1С** по идентификатору. Связку изобретать не нужно, механизм работает.

## Что меняется у карточки

Пометка «в 1С не выгружен» снимается. Записывается идентификатор из 1С.

## Если выгрузка прошла частично

Часть товаров могла не создаться из-за ошибки. Идентификаторы записываем только тем, кто реально создан. Остальные остаются помеченными и уйдут при следующей выгрузке — повторно те же товары не создадутся.
