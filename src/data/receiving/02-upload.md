# Шаг 2. Загрузка файла и сопоставление колонок

## Задача шага

Загрузить файл поставщика так, чтобы зашёл **любой формат**, а не только тот, что прислало М-Видео. Следующий поставщик назовёт колонки иначе, переставит их местами, добавит своих — система должна справиться без переделки.

Механизм тот же, что в загрузке счетов: показываем, что нашли в файле, и даём сопоставить с нашими полями.

## Как выглядит

**1. Выбор файла.** Кнопка загрузки, принимает xlsx. Файл читается на сайте, ничего никуда не пересылается вручную.

**2. Экран сопоставления.** Система вытаскивает заголовки из файла и показывает списком. Напротив каждого — выпадающий список наших полей. Знакомые названия подставляются автоматически: «Barcode» → штрихкод, «Бренд» → бренд. Незнакомое оставляем пустым или выбираем руками.

Лишние колонки файла просто не сопоставляем — они не попадут в базу.

Под каждым заголовком показываем пример значения из первой строки, чтобы было понятно, что это за колонка. Особенно важно для случаев вроде «Кондиция», где имя колонки врёт.

**3. Проверка перед записью.** Показываем итог:

- прочитано строк
- из них новых
- уже есть в базе (по штрихкоду)
- с незаполненными полями

Только после этого кнопка «Загрузить».

**4. Запись.** Строки уходят в таблицу приёмки. Повторы по штрихкоду пропускаются.

## Сохранение схемы

Сопоставление запоминается под именем поставщика. Второй файл от М-Видео разложится сам — экран сопоставления покажется уже заполненным, останется нажать «Загрузить».

Схему можно поправить: если поставщик поменял формат, меняем сопоставление и сохраняем заново.

## Много файлов подряд

Файлов от одного поставщика может быть много: партии приходят одна за другой. Таблица приёмки **копится** — каждая загрузка добавляет строки к тем, что уже есть.

## Обязательные поля

Без чего строка не примется:

- штрихкод (иначе нечем опознать единицу)
- техническое наименование

Остальное желательно, но не критично. Строки без бренда, модели или товарной группы загрузятся — просто не дадут полного красивого имени, и это будет видно на шаге 4.
