# Шаг 4. Каталог приёмки

## Задача шага

Превратить технические наименования в человеческие и сложить их в отдельный каталог для российских продаж.

Красивое имя собирается из трёх колонок: **товарная группа + бренд + модель**. Например, из `.Кофеварка JVC JK-CF34/19` получается `Кофеварка капельного типа JVC JK-CF34`.

Всё считает сайт: проходит по таблице приёмки, склеивает колонки, схлопывает дубли, показывает результат. Руками ничего не готовится.

## Сборка наименований

Кнопка «Собрать наименования». Сайт проходит по всей таблице приёмки и выдаёт сообщение:

> Готово N наименований. У M заполнены все три составляющие.

Дубли схлопываются: одна и та же модель приходит десятками штук, но в каталог попадает **одним наименованием**. На данных М-Видео из 16 945 строк выходит порядка двух тысяч имён — точное число считает сайт при каждом запуске.

Если у части строк не хватает бренда, модели или товарной группы — это видно сразу в сообщении.

## Экран просмотра

Кнопка «Просмотреть» открывает таблицу собранных наименований.

**Галочки** у каждой строки.

**Фильтры** по трём колонкам — товарная группа, бренд, модель. Плюс отдельный фильтр «неполные» — показать только те, где не хватает составляющих.

**Кнопки:**
- «Выбрать всё в фильтре» — отмечает то, что сейчас на экране, а не всю таблицу
- «Снять выбор»
- «Загрузить выбранные в каталог приёмки»

## Что попадает в каталог

- **Наименование** — красивое, склеенное из трёх частей
- **Категория** — из колонки «Направление» файла. 39 значений: Пылесосы, Кухонная техника, Уход за одеждой, Климат Зима и прочие. Нужна, чтобы оптовику было проще выбирать
- **Группа** — М-Видео (и далее по поставщикам)
- **Упаковка есть/нет** — колонка появляется, когда товар проверен
- **Цены** — в российских рублях

## Проверка на дубли

Каталог пополняется не за один раз: файлы приходят партиями, часть имён уже залита. При загрузке система проверяет, нет ли такого имени в каталоге, и повторно его не создаёт.

## Когда это делать

**В любой момент.** Приёмка идёт по техническим наименованиям и каталога не ждёт — можно сначала принять весь товар, а имена залить потом. Или наоборот.

## Отношение к основному каталогу

Каталог приёмки — второй, отдельный. Существующий сделан для Беларуси, цены в белорусских рублях. Этот — для России, цены в российских.

Что-то будем перекидывать из приёмки в основной. В дальнейшем объединим: один каталог с ценами в российских рублях, для остальных стран пересчёт по текущему или зафиксированному курсу.
