# Шаг 8. Заявки и отгрузка

## Задача шага

Связать приёмку с существующим механизмом заявок: собрать список для оптовика из каталога приёмки и при отгрузке списать остатки со склада.

## Переключатель каталога

При составлении заявки появляется выбор каталога:

- основной (белорусский, цены в белорусских рублях)
- каталог приёмки (российский, цены в российских рублях)

Переключатель виден **не всем** — право настраивается на шаге 3. Нет права — нет и переключателя, человек работает с обычным каталогом и ничего лишнего не видит.

## Выбор склада

Переключились на каталог приёмки — сразу второй выбор: **откуда берём товар**.

- со склада **СГП**
- со склада **Под ремонт**

Отпускаем с обоих: рабочее идёт одним оптовикам, нерабочее под восстановление — другим.

Товары показываются те, что реально есть на выбранном складе, с доступным количеством.

## Списание при отгрузке

Отгрузка заявки, собранной из каталога приёмки, **уменьшает остатки** на выбранном складе. Списание идёт **по техническим наименованиям**, поштучно — система сама подбирает конкретные единицы.

Заявка из основного каталога остатки не трогает: там учёта по складам нет.

## Два документа на выходе

**Накладная оптовику** — красивые наименования с общим количеством. Оптовику незачем видеть семнадцать строк `.Кофеварка JVC JK-CF34/19`, `/20`, `/21` — он видит `Кофеварка капельного типа JVC JK-CF34, 17 шт.`

**Документ списания** — технические наименования, поштучно. Нужен для учёта: видно, какие именно единицы ушли со склада.
